# まるごとウェブ制作所 公式サイト

小さなお店・事業者向けのホームページ制作業「まるごとウェブ制作所」の公式サイト。
ビルドツール不要の静的HTML/CSSのみで構成(どのレンタルサーバーにもそのまま置ける)。

## 構成

```
index.html        トップ
ryokin.html       料金のご案内(2プラン+お世話係+FAQ)
jisseki.html      制作実績(デモサイトへのリンク)
jigyousha.html    事業者向け高単価メニュー
profile.html      自己紹介
contact.html      お問い合わせ
assets/style.css  共通スタイル(藍色×白・BIZ UD書体)
demo/cafe/        制作例デモ「木漏れ日珈琲」(3ページ・noindex)
```

## プレビュー

`index.html` をブラウザで開くだけ。

## 公開

ディレクトリ一式をサーバーのドキュメントルートにアップロードする。
公開先ドメイン(予定): marugoto-web.jp

## メモ

- 電話番号・担当名は実物。デモサイトの店舗情報はすべて架空
- AI研修メニューは `jigyousha.html` 内にコメントアウトで温存
- LINE案内は `contact.html` 内にコメントアウトで温存(公式アカウント開設後に解禁)
